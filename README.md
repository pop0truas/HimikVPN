# HimikVPN

Android 7.0+. Версия **0.3.2-beta**.

- [Скачать ARM64 APK — 57,5 МБ](https://github.com/pop0truas/HimikVPN/releases/download/v0.3.2-beta/HimikVPN-0.3.2-beta-arm64.apk)
- [Универсальный APK — 247,7 МБ](https://github.com/pop0truas/HimikVPN/releases/download/v0.3.2-beta/HimikVPN-0.3.2-beta.apk)
- [Релиз, контрольные суммы и лицензии](https://github.com/pop0truas/HimikVPN/releases/tag/v0.3.2-beta)

Установите поверх предыдущей бета-версии и обновите серверы в разделе «Аккаунт → Подписка». При первом подключении подтвердите запрос VPN. Пакет `ru.himikvpn.preview` сохранён.

Конфигурации загружаются непосредственно из subpage `vpn.himiksound.ru`: Xray JSON сохраняет DNS, балансировщики, маршрутизацию и burst observatory. Доступны 🇪🇺 «Автовыбор» с территорией Европы и 🇷🇺 «Белые списки (LTE)» с территорией России. URI VLESS/Hysteria2 также поддерживаются. Официальное ядро XTLS/libXray v26.9.30 сохранено.

Интерфейс использует apple-design: пружинный отклик всех кнопок, компактные раскрываемые карточки устройств с удалением через админку и обновление разделов без надписи загрузки при наличии кеша. Выключенная планета светлая, включённая — тёмная. Покупка и продление доступны на сайте/в боте.

Трафик текущего туннеля показывает получено/отправлено из счётчиков TUN ядра. История аккаунта за 30 дней показывает названия соответствующих хостов вместо внутренних имён нод и общие суммы. Исторические направления и разделение общей ноды между несколькими хостами панель не предоставляет.

Пять реальных конфигураций получены из subpage и импортированы. Автовыбор на Android-эмуляторе подтвердил HTTPS через туннель и рост счётчика трафика. API истории вернул четыре строки с именами хостов. Целевые проверки импорта, сопоставления хостов и принадлежности удаляемого устройства прошли. Реальные устройства пользователей во время проверки не удалялись.

**Debug-beta.** Физический телефон и профиль LTE в мобильной сети с белыми списками пока не проверены. Ранее отдельные VLESS REALITY/XHTTP не подтвердили соединение в сети ПК, включая отдельный официальный Xray; причина не установлена и не объявляется исправленной этой версией. Нативный OAuth и постоянный системный kill switch недоступны. Небезопасный TLS, pinSHA256, Gecko и realm-ссылки отклоняются.

Репозиторий распространяет APK и документацию. Лицензии и сведения об исходниках ядра — в `THIRD_PARTY_NOTICES.zip` из релиза.
